# VitaFlow

A simple mobile-first 10-day routine tracker for meals, exercise, water and reminders.

## Features
- 10-day dashboard and progress
- Editable meals, exercise details, times and reminders
- Water target and daily glass tracking
- Local browser storage
- Optional browser notifications
- Responsive mobile/desktop UI

Open `index.html` directly or host the repository as a static site.

**Reminder limitation:** browser reminders depend on permissions and platform behavior. VitaFlow checks reminders while the page is active; it does not guarantee OS-level alarms when the browser is fully closed.

**Health note:** VitaFlow is a routine organizer, not medical advice. If the user is still growing, meal and exercise plans should be reviewed with a parent/guardian or qualified healthcare professional.
